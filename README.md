**2. 一号一环境。** 单独的浏览器配置文件或者指纹浏览器，Cookie、本地存储、插件列表互不干扰。不要在同一个浏览器里登录多个Google账号，这是风控的高频触发点。

**5. 出现"Something went wrong"先别慌。** 这个提示很多时候是IP节点临时被标记，换个干净节点、清缓存重登可能就恢复。但如果出现"Gemini isn't currently supported in your country"，基本是账号地区问题，成品号一般不会出现这个，代充到自己账号上的话要确认账号地区是美区或港区。
